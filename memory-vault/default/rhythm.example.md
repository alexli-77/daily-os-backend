## 工作日

- 工作时间 09:30-18:30，19:00 之后不要再排工作任务。
- 上午留给需要安静的活，会议尽量排下午。

## 休息日

- 只处理已经逾期的事，其余时间留给生活。
- 不要把下周的活提前拿到周末做。

## 固定占用

- 周二、周四 19:00-21:00 教球，不可占用。
- 周日 20:00 周复盘。

## 其他

- 连续加班三天后，第四天按休息日排。
